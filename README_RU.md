# ISTQB Sample Exam A — исправление 6 вопросов

Назначение: доработать только вопросы №14, 20, 21, 22, 23 и 33 из официального Sample A v1.7.

**Что меняется**

- №20: поддержка однобуквенных и однозначных ответов (например `3`, `4`, `5`, `6`) в мобильном текстовом формате.
- №14, №21, №22, №23, №33: пробуем гибридное отображение, где условие и ответы — нативный текст, а отдельная таблица/схема — компактное изображение.
- Если не удаётся надёжно распознать границы таблицы или варианты ответа, импортёр оставляет исходную картинку PDF (не выдумывает текст).
- Остальные 34 вопроса остаются на том же алгоритме распознавания.

**Внимание:** скрипт проверен на специально созданных тестовых PDF; реальный официальный Sample A должен пройти финальную проверку на вашем компьютере. PDF с материалами ISTQB в архив не включён.

## 1. Сделайте резервную копию текущего проекта

Сохраните текущую рабочую версию Git Commit (не добавляйте защищённые материалы в публичный репозиторий без разрешения).

## 2. Скопируйте из ZIP только три файла с заменой

- `tools/import_istqb_samples.py`
- `app/src/main/java/com/istqb/prep/data/OfficialSampleRepository.kt`
- `app/src/main/java/com/istqb/prep/ui/screens/Screens.kt`

Распакуйте ZIP в корневую папку `C:\AndroidProjects\ISTQB_Prep_App` с сохранением структуры каталогов. Это должны быть именно новые версии файлов.

## 3. Импортируйте только Sample A

В Terminal Android Studio, находясь в корне проекта:

```powershell
py tools/import_istqb_samples.py --project-root . --sets A
```

Скрипт выводит в конце `Detailed A fixes` и `Remaining PDF questions`.

Желаемый результат (не гарантируется до проверки реального PDF):

```
Detailed A fixes: [(14, 'hybrid'), (20, 'text'), (21, 'hybrid'), (22, 'hybrid'), (23, 'hybrid'), (33, 'hybrid')]
Remaining PDF questions: []
```

Если статус `pdf` у какого-либо из шести номеров остался — сообщите строку `Detailed A fixes`: скрипт безопасно сохранил исходное изображение, а нужную границу таблицы ещё надо уточнить.

## 4. Проверка Android

После успешного импорта: `Build → Make Project`, затем `Run` на телефоне. Проверьте сначала №20 и №21; для №21 таблица должна быть видна отдельно между условием и вариантами, а варианты ответов должны содержать текст.

Пока не импортируйте B, C, D и не меняйте `Models.kt`, `IstqbViewModel.kt` или статистику.
