# ISTQB Prep Android App (Kotlin + Jetpack Compose)

Готовый проект Android-приложения для подготовки к экзамену **ISTQB Certified Tester Foundation Level (CTFL v4.0)**.

## Что реализовано в текущей сборке (Режим Силлабуса):
1. **Главный экран** со всеми 5 основными разделами + раздел статистики:
   - `1) Обучение: Силлабус` — 6 модулей по всем главам силлабуса v4.0, теория + практическое задание в конце каждого модуля.
   - `2) Обучение: Полная книга` — архитектурная заглушка (готова к наполнению через JSON).
   - `3) Тест по Главам: Силлабус` — отдельные тесты по каждой из 6 глав.
   - `4) Тест по Главам: Книга` — архитектурная заглушка.
   - `5) Режим экзамена` — билеты + случайная выборка из разных глав без повторений, таймер 60 минут, проходной балл 65%.
2. **Подробный разбор ошибок**:
   - При неправильном ответе показывается, *почему именно выбранный вариант неверен*, а затем выводится правильный ответ с объяснением.
3. **Статистика и работа над ошибками**:
   - Сохраняет историю ответов локально (`SharedPreferences`) и позволяет запустить отдельный тренажер только по ошибочным вопросам.
4. **Режимы отображения (переключатель в верхней панели)**:
   - **Стандарт** — классическая светлая тема Material 3.
   - **Чтение** — теплый фон сепии (`#F4ECD8`), шрифт с засечками (`Serif`) и увеличенный межстрочный интервал.
   - **E-Ink (Электронные чернила)** — высококонтрастный черно-белый режим без теней с четкими рамками.
5. **Адаптивность (Смартфоны и Планшеты)**:
   - Используется `WindowSizeClass`: на планшетах сетка меню перестраивается в 2–3 колонки, а в разделе обучения открывается двухпанельный интерфейс (список модулей слева, теория справа).

## Как запустить в Android Studio:
1. Распакуйте архив.
2. Откройте папку `ISTQB_Prep_App` в **Android Studio** (`File -> Open`).
3. Дождитесь синхронизации Gradle и нажмите **Run** на эмуляторе смартфона, планшета или на реальном Android-устройстве.
4. База теории и вопросов находится в `app/src/main/assets/istqb_syllabus_v4.json` — вы можете легко добавлять туда новые вопросы и главы книги (`"source": "BOOK"`).
